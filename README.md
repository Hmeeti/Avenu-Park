# Park Avenue Hotel & Cafe — электронное меню

Сайт-меню для гостей: открывается по QR-коду с телефона, работает на русском, казахском и английском языках, со светлой и тёмной темой. Гость может посчитать свой счёт (заказ никуда не отправляется).

**Адрес сайта:** https://hmeeti.github.io/Avenu-Park/

Сайт — обычные файлы, без программ и сборки. Его можно открыть двойным кликом по `index.html`.

## Где что лежит

| Файл / папка | Что внутри |
|---|---|
| `data/menu.js` | Все блюда и напитки: названия, составы, цены, фото |
| `data/config.js` | Данные заведения: телефон, часы работы, % обслуживания, официанты, Wi-Fi, адрес, правила |
| `assets/food/` | Фото блюд |
| `assets/logo/`, `assets/icons/` | Логотипы и иконки |
| `index.html`, `css/`, `js/` | Сам сайт (менять не нужно) |
| `reference/menu.pdf` | Печатный макет меню — только для справки |
| `tools/optimize-photos.py` | Скрипт подготовки фото |

Файлы удобно править в любом текстовом редакторе (Блокнот, VS Code) или прямо на GitHub: откройте файл → значок карандаша → внесите правку → **Commit changes**. Через 1–2 минуты сайт обновится.

> Меняйте только текст в кавычках и числа. Запятые, скобки и кавычки вокруг должны остаться на месте.

## Как поменять цену

1. Откройте `data/menu.js` и найдите блюдо поиском (Ctrl+F) по названию, например `Латте`.
2. Ниже найдите строку `"price": 1290,` и поменяйте число. Цена пишется без пробелов и без знака ₸.
3. У напитков с несколькими объёмами цены стоят в блоке `"variants"`:
   ```js
   "variants": [
     { "label": "0,4 л", "price": 790 },
     { "label": "1 л", "price": 1390 }
   ],
   ```

## Как добавить блюдо

Скопируйте блок любого похожего блюда (от `{` до `},`) и вставьте рядом. Затем поменяйте:

- `"id"` — уникальное имя латиницей без пробелов, например `"salad-caprese"`. Под этим же именем будет лежать фото;
- `"category"` — раздел (`salads`, `coffee`, `pizza` и т. д., список разделов в начале файла);
- `"name"` и `"description"` — на трёх языках (`ru`, `kk`, `en`). Если перевода нет, оставьте `""`: покажется русский текст;
- `"price"` — цена;
- `"photo": null` — пока фото нет.

Полезные поля:

- `"available": false` — блюдо временно закончилось: будет показано серым с пометкой «Нет в наличии»;
- `"tags": ["hit"]` — метки: `hit` (Хит), `new` (Новинка), `veg` (Вегетарианское), `spicy` (Острое), `halal`.

Чтобы удалить блюдо, удалите его блок целиком.

## Как добавить фото

**Способ 1 — автоматически (рекомендуется).**

1. Назовите фото так же, как `id` блюда: `coffee-latte.jpg`, `bf-english.jpg` и положите в `assets/food/`.
2. Один раз установите Python (https://www.python.org) и выполните `python -m pip install pillow`.
3. В папке проекта выполните `python tools/optimize-photos.py`.

Скрипт обрежет фото до 4:3, сожмёт его (WebP + JPG) и сам пропишет фото в `data/menu.js`. Исходники он перенесёт в `assets/food/_originals/`.

**Способ 2 — вручную.** Положите в `assets/food/` один файл, например `coffee-latte.jpg` (желательно 960×720, до 150 КБ), и у блюда напишите `"photo": "coffee-latte.jpg"`.

Если в разделе кухни нет фото, вместо него показывается аккуратная заглушка с эмблемой. Разделы бара без единого фото показываются компактным списком.

## Настройки заведения (`data/config.js`)

- **Процент обслуживания:** `serviceChargePercent: 15`. Если поставить `0`, строка «Обслуживание» исчезнет.
- **Официанты:** `waiters: ['Айгерим', 'Данияр']`. Пока список пуст, кнопка «Выбрать официанта» скрыта.
- **Wi-Fi:** `wifi: { name: 'ParkAvenue', password: '12345678' }`.
- **Адрес и карта:** `address: '...'`, `mapUrl: 'https://2gis.kz/...'`.
- **Завтраки, заезд, выезд:** `breakfastHours`, `checkIn`, `checkOut`.
- **Телефоны, Instagram, часы работы, приветствие, правила** — там же.

Пустые поля на сайте просто не показываются.

## Публикация на GitHub Pages

Сайт уже опубликован. Если понадобится включить заново: репозиторий на GitHub → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**. Через пару минут сайт будет доступен по адресу выше.

После любой правки подождите 1–2 минуты и обновите страницу.

## QR-код для столов

Сделайте статический QR-код на бесплатном сервисе, например [QRCode Monkey](https://www.qrcode-monkey.com/) (без регистрации, код не «истекает»):

1. Вставьте ссылку `https://hmeeti.github.io/Avenu-Park/`.
2. При желании загрузите эмблему `assets/logo/logo-emblem.png` в центр кода.
3. Скачайте PNG или SVG для печати.

Перед печатью проверьте код камерой телефона.
